# Splunk — Complete Learning and Interview Preparation

## Objective

Develop practical Splunk skills from beginner to intermediate level, focusing on SOC Analyst L1 and L2 responsibilities.

This section covers:

- Splunk Fundamentals.
- Splunk Architecture.
- Data Ingestion and Forwarders.
- Syslog and HEC.
- Search Processing Language (SPL).
- Security Monitoring.
- Detection Engineering.
- Event Correlation.
- Threat Hunting.
- Practical SOC Projects.
