# SOC Preparation

A structured cybersecurity learning and practical training repository documenting my journey toward becoming a SOC Analyst.

This repository contains my learning notes, hands-on labs, practical exercises, Splunk searches, security investigations, projects, diagrams, and interview preparation materials.

The objective is to strengthen cybersecurity fundamentals, develop practical SOC skills, and build the knowledge required for a SOC Analyst role.

---

## Learning Roadmap

My SOC preparation is organized into the following areas:

### 1. TryHackMe

- Cybersecurity fundamentals.
- Networking fundamentals.
- Linux fundamentals.
- Windows fundamentals.
- Security concepts and practical exercises.

### 2. Splunk

- Splunk architecture and fundamentals.
- Searching and Search Processing Language (SPL).
- Working with events and fields.
- Reports, dashboards, and visualizations.
- Security monitoring and investigation.
- Detection engineering and threat hunting.

### 3. SOC Practical Projects

Independent, end-to-end projects that combine knowledge from multiple modules to simulate real-world SOC activities.

Examples:

- Linux Security Monitoring.
- Brute-Force Attack Investigation.
- VPN and Linux Authentication Correlation.
- Threat Intelligence Investigation.
- Edge Infrastructure Security Monitoring.
- SOC Monitoring Dashboard.

### 4. Interview Preparation

- Technical interview questions.
- Splunk and SPL questions.
- Linux and networking questions.
- SOC investigation scenarios.
- Incident response and troubleshooting scenarios.
- Communication and incident reporting practice.
